## 1. Позиционирование: личный бренд + студия в одном аккаунте

Один аккаунт `@mirelli.studio`. Вы в кадре и в голосе, студия это «рамка».

- **Для клиентов (малый бизнес):** рабочие демо автосервиса, клиники, ресторана, коворкинга.
- **Для профессионального имиджа:** «человек, который собирает всё сам: от Telegram-ботов и FastAPI до AI-агентов в браузере». Это подтверждается репозиториями (ниже), а не словами.
- **Формула bio:** кто вы → кому помогаете → доказательство → действие. Пример:
  `Dima · builder behind Mirelli Studio` / `Booking, systems & Telegram bots for small business` / `Live demos ↓`

Главное правило: **не смешивайте аудитории в одном ролике.** Клиентам показываем бизнес-результат, инженерам и работодателям показываем техническую глубину. В ленте это разные рубрики.

## 6. Шаблон Reel (сценарий + хук)

- **0–3 с:** текст на экране + голос с конкретикой. Примеры:
  - «Я собрал свой Claude Code в браузере. Любая модель, свой ключ.» (SparkyIDE)
  - «Вставил вакансию, получил CV под неё. Без выдумок.» (CV)
  - «Банк прислал SMS: бот сам записал трату в таблицу.» (DizelFinance)
  - «Гость заказывает в Telegram, ресторан видит всё в панели.» (Restaurant)
- **3–22 с:** живая запись экрана одного сценария, без «мы предлагаем комплексные решения».
- **22–28 с:** CTA с отправкой: «Перешлите владельцу ресторана» или комментарий `DEMO`.
- Всегда: оригинальное видео, субтитры, звук с лицензией (не тренд-треки), без водяных знаков.

## 7. Честные рамки

- Не называть клиентов и не показывать их данные без разрешения; в демо только вымышленные данные (как сейчас).
- Не обещать результаты («+30% записей»): только реально измеренное с согласием.
- Про tradingMind: никаких «сигналов» и советов по инвестициям; это учебный paper-trading, иначе юридический риск.
- Если AI собирал часть кода, это нормально, но не выдумывайте «команду из 20 разработчиков».
